The link between the radio mesh and the digital world.

Aegis Hub (Base Station)

The "Gateway" device. It sits at the Command Center, receiving LoRa signals from the field and pushing them to the dashboard via Ethernet or Wi-Fi.

$500 / unit
  • • High-Performance Compute: Powered by Raspberry Pi 5 to handle thousands of concurrent messages.
  • • Multi-Channel Gateway: Uses SX1302 Concentrator to listen on 8 channels simultaneously.
  • • Local Hosting: Can run the software offline (Air-Gapped) or sync to the cloud.

NOT a Single Point of Failure:
Unlike competitor base stations, the Aegis Hub is optional for local communication. If the Hub is destroyed, the local mesh network remains 100% operational for device-to-device messaging.
