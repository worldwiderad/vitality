System Architecture.

A breakdown of the physics, topology, and security protocols powering the Aegis ecosystem.

1. The Physics: LoRa vs. Wi-Fi

How do we get 20km range without huge antennas? Physics.

The "Whisper" Technique

Standard radios (like Wi-Fi) scream loudly but have poor hearing. They need a "line of sight" and high power.

Aegis uses LoRa (Long Range) modulation. Instead of shouting, it uses a "chirp" signal that sweeps across frequencies. This allows our receiver to decode signals that are below the noise floor (buried in static).

It's like being able to hear a whisper across a crowded stadium. This provides immense range and penetration through dense forests and mountain ranges.

Feature Standard Wi-Fi Aegis (LoRa)
Range ~100 meters 15 - 20 km (Wilderness)
Autonomy Hours Months(Battery)
Environment Indoor / Urban Forests & Mountains
Bandwidth High (Video/Voice) Low (Text/GPS Only)

*We trade bandwidth for reliability. You can't stream Netflix, but you can send a location pin from a valley where sat-phones fail.

2. The Topology: Distributed Mesh

Why the network survives when half the devices are destroyed.

The "Self-Healing" Concept

In a standard network (like 4G), if the cell tower falls, everyone loses signal. This is a Star Topology—a single point of failure.

Aegis uses a Mesh Topology. There is no central server. Every single device (Node) acts as a router/repeater for everyone else.

Scenario: The "Broken Bridge"

1. Rescuer A wants to message Command Post Z.
2. The direct path is blocked by a mountain.
3. The message automatically hops to Node B, then Node C, then to Z.
4. If Node B runs out of battery? The network instantly re-routes through Node D.

Infinite Scalability

Unlike localized systems, Aegis is designed for country-scale deployment.

  • Infinite Hopping:
    To get a message from one side of Japan to the other, the packet simply keeps hopping. There is no artificial limit to the network's size.
  • Packet Deduplication:
    Nodes remember message IDs to prevent "echoes," ensuring efficiency even when hopping thousands of times.
  • Store & Forward:
    If a node is alone, it holds the message until it reconnects with another node, then delivers it.

3. Security Architecture

In a conflict zone, metadata is as dangerous as the content. We protect both.

Physical Isolation (Air-Gapped)

You have to be there to hack it. Unlike the internet, which can be attacked from anywhere in the world, an attacker must be physically within range of our radio signals to even attempt an intercept.

AES-256 Encryption

Every packet is encrypted using AES-256. Even if a hostile actor is in range and records the signal, they will see nothing but random noise.

Zero-Trust Keys

Encryption keys are pre-shared physically or generated locally. We (Vitality) do not hold a "master key." If we are subpoenaed, we cannot unlock your data.
