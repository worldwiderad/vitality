System Architecture.

A breakdown of the physics, topology, and security protocols powering the Aegis ecosystem.

1. The Physics: LoRa Modulation

Aegis does not use standard Wi-Fi or Cellular radio. We utilize LoRa (Long Range), a spread-spectrum modulation technique derived from Chirp Spread Spectrum (CSS) technology.

Why it works

Standard radios (like Wi-Fi) shout loudly but can't hear well. LoRa "whispers" using a specialized chirp that sweeps across frequencies. This allows our receiver to decode signals that are actually below the noise floor (up to -148dBm).

  • Link Budget: 168dB (Theoretical Max)
  • Frequency: 433/868/915 MHz (ISM Bands)
  • Penetration: Can pass through dense urban concrete or deep forest canopies where 4G fails.

Managed Flooding Algorithm

Aegis uses a modified flooding protocol. When a message is sent, it is picked up by all nearby nodes. Those nodes check if they have seen the message ID before:

  1. If New: The node rebroadcasts the message to its neighbors.
  2. If Seen: The node discards it to prevent "packet storms."
  3. Hop Limit: Messages expire after 3-7 hops to preserve network bandwidth.

Result: A self-healing path that forms instantly, even if 50% of the nodes are destroyed.

3. Security: The "Black Box" Approach

In a conflict zone, metadata is as dangerous as the content. We protect both.

AES-256 Encryption

Every packet is encrypted using AES-256 (Advanced Encryption Standard). Even if a hostile actor intercepts the radio wave, they see only random noise.

Zero-Trust Keys

Encryption keys are pre-shared physically or generated locally. We (Vitality) do not hold a "master key." If we are subpoenaed, we cannot unlock your data.

Metadata Obfuscation

Our proprietary header protocol minimizes visible metadata. To an outsider, a "Heartbeat" ping looks identical to a distress signal.
