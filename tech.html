System Architecture.

A breakdown of the long-range modulation, mesh topology, and security protocols powering the Aegis ecosystem.

1. The Physics: LoRa vs. Wi-Fi

How do we get 20km range without huge antennas?

The "Whisper" Technique

Standard radios scream loudly but have poor hearing. They need a line of sight and high power to maintain a connection.

Aegis uses LoRa (Long Range) modulation. Instead of shouting, it uses a chirp signal that sweeps across frequencies. This allows our receiver to decode signals that are below the noise floor.

This modulation provides a massive "Link Budget" advantage. While Wi-Fi fades after a few walls, LoRa signals can diffract around obstacles and reflect off terrain features, maintaining packet integrity where other protocols show zero bars.

2. The Topology: Distributed Mesh

Why the network survives when half the devices are destroyed.

The "Self-Healing" Concept

In a standard network, if the cell tower falls, everyone loses signal. This is a Star Topology and represents a single point of failure.

Aegis uses a Mesh Topology. There is no central server. Every single device acts as a router for everyone else.

Scenario: The "Broken Bridge"

1. Rescuer A wants to message Command Post Z.
2. The direct path is blocked by a mountain.
3. The message automatically hops to Node B, then Node C, then to Z.
4. If Node B runs out of battery, the network instantly re-routes through Node D.

Infinite Scalability

Unlike localized systems, Aegis is designed for country-scale deployment.

  • Infinite Hopping:
    To get a message from one side of Japan to the other, the packet simply keeps hopping. There is no artificial limit to the network's size.
  • Packet Deduplication:
    Nodes remember message IDs to prevent echoes, ensuring efficiency even when hopping thousands of times.
  • Store & Forward:
    If a node is alone, it holds the message until it reconnects with another node, then delivers it.

3. Security Architecture

We built Aegis to be secure against both physical and digital threats.

Physical Isolation (Air-Gapped)

You have to be there to hack it. Unlike the internet, an attacker must be physically within range of our radio signals to even attempt an intercept.

AES-256 Encryption

Every packet is encrypted using AES-256. Even if a hostile actor is in range and records the signal, they will see nothing but random noise.

Zero-Trust Keys

Encryption keys are pre-shared physically or generated locally. We do not hold a "master key."

Engineering FAQ

Can the network be jammed? ▼

While no radio system is un-jammable, Aegis is highly resistant. We use CSS (Chirp Spread Spectrum), which spreads the signal across a wider bandwidth. A jammer must overpower the entire spectrum to stop the signal. Furthermore, the mesh topology allows the network to route around a localized jamming source.

What happens during a nuclear winter / prolonged storm? ▼

The Public Node features an 80,000mAh LiFePO4 battery. The system defaults to a deep sleep mode, waking only to repeat messages or interact with a user. This allows for over 6 months of operation even with zero solar input.

Is this legal on civilian frequencies? ▼

Yes. Aegis operates on the ISM bands (Industrial, Scientific, and Medical). These are license-free bands. We strictly adhere to the duty cycle and transmission power limits set by the FCC, ETSI, and regional authorities, ensuring legal operation without requiring user licenses.

How does it differ from Starlink? ▼

Starlink requires a $500 dish, 100W of power, and a clear view of the sky. It connects to the internet.

Aegis connects people to people locally. It requires <1W of power, works in dense forests, costs $150, and creates its own offline network. We are the "last mile" solution where satellites cannot reach or are too expensive.
